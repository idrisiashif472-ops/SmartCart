# 🛒 SmartCart

SmartCart is a Java-based Android self-checkout shopping application designed to make supermarket shopping faster and more convenient.

## 🚀 Features

- 🔐 User Registration & Login
- 👨‍💼 Separate Admin Login & Dashboard
- 📷 Barcode Scanning using Google ML Kit
- 🛍️ Product Search & Details
- 🛒 Smart Cart Management
- 💰 Budget & Savings Tracking
- 📦 Real-Time Stock Management
- 🏷️ Product Discounts & Offers
- 💳 Checkout & Stock Verification
- 🧾 Digital Bill Generation
- 📜 Bill History
- 🖼️ Product Image Search
- 📊 Admin Sales & Inventory Statistics

## 🛠️ Technologies

- Java
- Android Studio
- XML
- Firebase Authentication
- Cloud Firestore
- Google ML Kit
- Serper Image Search API
- OkHttp

## 🎯 Project Goal

The main goal of SmartCart is to provide a self-checkout experience where customers can scan products, manage their purchases, monitor their spending, and generate a digital bill while administrators can efficiently manage products, inventory, and sales.
